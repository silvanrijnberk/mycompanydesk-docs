So legen Sie eine Ausgabenkategorie fest oder ändern sie:
1. Öffnen Sie die Ausgabe im Bearbeitungsmodus
2. Suchen Sie das Dropdown „Kategorie"
3. Wählen Sie eine Kategorie aus Ihrer Arbeitsbereichsliste (Systemstandards oder selbst hinzugefügte Kategorien)
4. Speichern Sie die Ausgabe

Die Standardkategorien folgen der niederländischen Steuererklärung, sodass Ihre Buchhaltung zur Aangifte passt. Eigene Kategorien fügen Sie unter **Einstellungen > Ausgabenkategorien** hinzu und bearbeiten, archivieren oder löschen sie dort. Ist eine Kategorie bereits mit Ausgaben oder wiederkehrenden Ausgaben verknüpft, können Sie sie nicht löschen; archivieren Sie sie, damit sie im Formular ausgeblendet wird. Eine archivierte Kategorie erscheint weiterhin im Dropdown für Ausgaben, mit denen sie bereits verknüpft ist, mit dem Zusatz "(archiviert)", sodass Sie diese Ausgaben weiter bearbeiten können. Verwenden Sie Kategorien konsistent, damit Filter, Listen und Berichte leicht zu prüfen bleiben.
