So bearbeiten Sie eine Rechnung:
1. Öffnen Sie die Rechnung aus der Liste
2. Klicken Sie auf "Bearbeiten"; das ist möglich, solange die Rechnung ein Entwurf ist oder zwar abgeschlossen, aber noch nicht versendet
3. Ändern Sie Positionen, Kunde, Daten oder Bedingungen
4. Speichern Sie die aktualisierte Rechnung

Sobald eine Rechnung beim Kunden war, ist sie gesperrt und lässt sich nicht mehr bearbeiten: das gilt für eine Rechnung, die versendet oder per E-Mail verschickt wurde, die als bezahlt markiert ist, oder deren PDF Sie heruntergeladen oder geteilt haben. Auf der Seite steht, welcher dieser Fälle zutrifft (heruntergeladen oder geteilt, ohne je gemailt zu sein, bekommt einen eigenen Hinweis: Rechnung gesperrt: bereits beim Kunden), und die gesetzlich vorgeschriebenen Angaben werden schreibgeschützt. Eine Gutschrift und, falls nötig, eine neue Rechnung ist der Weg für Änderungen; eine fertige Rechnung, die den Kunden nie erreichte, können Sie weiterhin bearbeiten.

Tipp: Fehler auf einer versendeten Rechnung? Mit einer Gutschrift plus einer neuen Rechnung bleiben Ihre Nummerierung und MwSt.-Unterlagen sauber.
