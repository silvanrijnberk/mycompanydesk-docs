Eine Ausgabe hat eine Kategorie und ein Projekt. So verteilen Sie einen Beleg auf mehrere Kategorien oder Projekte:
1. Legen Sie für jeden Teil eine eigene Ausgabe an
2. Weisen Sie jeder Ausgabe die passende Kategorie oder das passende Projekt zu
3. Verweisen Sie in jeder Ausgabe auf denselben Beleg
4. Notieren Sie, wie Sie den Beleg aufgeteilt haben, und prüfen Sie, ob die Teile zusammen den Belegbetrag ergeben

Mit gleichen Notizen oder Belegverweisen bleiben die zusammengehörenden Ausgaben leicht auffindbar.
