So sichern Sie Ihre Daten:
1. Gehen Sie zu Einstellungen › „Daten herunterladen“
2. Laden Sie CSV-Exporte für Rechnungen, Kunden und Ausgaben oder das dort verfügbare Vollbackup herunter
3. Für eine vollständige Kopie nutzen Sie **Alles herunterladen** auf derselben Seite: eine ZIP mit den PDFs Ihrer Rechnungen, Angebote, Arbeitsaufträge und Verträge, Ihren Belegen, Dokumenten, E-Mails, Ihrer Website und Ihren Umsatzsteuer-Anmeldungen, dazu eine Prüfsicherungsdatei pro Jahr. Sie erhalten eine E-Mail, sobald sie fertig ist; die Inhaberin oder der Inhaber bzw. ein Admin kann sie einmal pro Tag anfordern
4. Prüfen Sie, ob die heruntergeladenen Dateien die benötigten Datensätze enthalten

Die CSV-Exporte von Rechnungen, Ausgaben und Ihrer Kundenliste sowie das Vollbackup sind in jedem Tarif kostenlos. Wenn Sie regelmäßig sichern, wählen Sie einen festen Zeitpunkt, zum Beispiel nach dem Abschluss jedes Quartals.
