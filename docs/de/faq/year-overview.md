So prüfen Sie ein ganzes Jahr in der App:
1. Öffnen Sie **Berichte** (Office)
2. Stellen Sie unter **Filter** den Zeitraum auf Jahr und wählen Sie das gewünschte Jahr
3. **Übersicht** zeigt die Kernzahlen; wechseln Sie zu Verkauf, Kunden, Kosten oder Cashflow für mehr Detail
4. Aktivieren Sie den Vergleich, um das Jahr neben einem früheren Jahr zu sehen

Die Gewinn-und-Verlust-Rechnung und den Jahresabschluss dieses Jahres finden Sie unter **Buchhaltung** (Office).

Tipp: Mit **Offene Rechnungen einbeziehen** steuern Sie, ob unbezahlte Rechnungen in die Summen einfließen.
