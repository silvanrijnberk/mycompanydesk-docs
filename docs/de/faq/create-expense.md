So fügen Sie eine Ausgabe hinzu:
1. Gehen Sie zu Ausgaben und klicken Sie auf „Hinzufügen“
2. Haben Sie einen Beleg? Klicken Sie auf „Beleg scannen“ oder laden Sie ein Foto oder PDF hoch. MyCompanyDesk liest Lieferant, Betrag und Datum aus und hängt den Beleg direkt an die Ausgabe. Prüfen Sie danach die eingetragenen Daten
3. Kein Beleg zur Hand? Tragen Sie die Daten selbst ein. Datum, Lieferant, Kategorie und Betrag sind Pflichtfelder; eine Ausgabe über 0,00 € lässt sich nicht speichern
4. Speichern Sie die Ausgabe

Brauchen Sie weitere Felder, etwa Fälligkeitsdatum, Kunde, Projekt oder Notizen? Wählen Sie im Bereich „Mehr Felder nötig?“, um das vollständige Formular zu öffnen. Einen Beleg, den Sie später bekommen, fügen Sie auf der Seite der Ausgabe mit „Beleg hochladen“ hinzu.

Das automatische Auslesen von Belegen nutzt KI-Scans: mit Desk 3 pro Monat, mit Office 200. Sind Ihre Scans aufgebraucht, wird der Beleg trotzdem gespeichert und Sie tragen die Daten selbst ein.
