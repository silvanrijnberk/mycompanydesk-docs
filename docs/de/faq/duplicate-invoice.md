So duplizieren Sie eine Rechnung:
1. Öffnen Sie die Rechnung, die Sie kopieren möchten
2. Klicken Sie oben auf „Mehr“ (auf dem Smartphone das Menü mit den drei Punkten). Bei einer bezahlten oder stornierten Rechnung steht „Duplizieren“ direkt oben
3. Wählen Sie „Duplizieren“
4. Es wird ein neuer Entwurf mit denselben Positionen und demselben Kunden erstellt, mit dem heutigen Datum
5. Passen Sie Datum, Beträge oder Details an und speichern Sie

Die Kopie übernimmt die Referenznummer und das verknüpfte Objekt aus der Originalrechnung, sodass Sie keine Bestellnummer oder Zuordnung zu einem Mietobjekt verlieren. Eine Gutschrift lässt sich nicht duplizieren.

Tipp: Praktisch für ähnliche Rechnungen an denselben Kunden, so müssen Sie nicht alle Positionen neu eingeben.
