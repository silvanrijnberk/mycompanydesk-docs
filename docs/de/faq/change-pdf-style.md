So ändern Sie den Stil Ihrer PDF-Rechnungen:
1. Gehen Sie zu Einstellungen › „Rechnungsgestaltung“
2. Klicken Sie unter „Aus meinem Corporate Design generieren“ auf „Aus Corporate Design generieren“ für ein Design in Ihrer eigenen Markenfarbe („Anderen Look ausprobieren“ liefert eine Alternative), oder wählen Sie selbst eine Vorlage
3. Passen Sie Akzentfarbe, Papierton, Schriften, Layout und Fußzeile an; die A4-Vorschau aktualisiert sich live
4. Änderungen werden automatisch gespeichert und gelten für alle neuen Rechnungen, Angebote und Erinnerungen

Tipp: Ihr Logo und Ihre Markenfarbe finden Sie unter Einstellungen › „Logo und Farbe“; das Designstudio baut darauf auf.

Tipp: Wenn Sie eine Rechnung oder ein Angebot betrachten, klicken Sie im Kopf der Dokumentvorschau (oder im Overflow-Menü auf Mobilgeräten) auf **Design anpassen**, um direkt zur Rechnungsgestaltung zu springen. Nach dem Bearbeiten kehren Sie zu dem Dokument zurück, von dem Sie gekommen sind.
