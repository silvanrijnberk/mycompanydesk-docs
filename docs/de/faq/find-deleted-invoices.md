Gelöschte Rechnungen finden Sie in Rechnungen: Klicken Sie über der Liste auf Filter und wählen Sie unter Anzeigen die Ansicht Papierkorb. Auf dem Smartphone nutzen Sie dafür die Filterschaltfläche oben. Wenn Sie archivierte Rechnungen meinen, nutzen Sie die Ansicht Archiv.

Nur Entwürfe ohne Rechnungsnummer lassen sich löschen oder archivieren. Eine finalisierte Rechnung landet also nie im Papierkorb; Sie finden sie in der normalen Liste, auch wenn sie storniert wurde.
