So prüfen, drucken oder laden Sie ein Angebot als PDF herunter:
1. Öffnen Sie das Angebot
2. Am Computer steht die Vorschau des Angebots bereits auf der Seite. Klicken Sie auf **Vollbild**, um sie groß anzusehen; im Kopf der Vorschau finden Sie auch Schaltflächen zum Drucken und zum PDF-Download
3. Auf dem Telefon wählen Sie im Menü mit den drei Punkten **Vorschau** oder **PDF herunterladen**
4. In der großen Vorschau nutzen Sie **Drucken** oder **PDF herunterladen**
5. Gehen Sie für Anpassungen zurück zum Angebot

Tipp: Die Vorschau nutzt Ihre aktuelle Rechnungsgestaltung. Um das Layout zu ändern, klicken Sie bei der Vorschau auf **Design anpassen**.
