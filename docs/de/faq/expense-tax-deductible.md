So erfassen Sie die Abzugsfähigkeit in der App:
1. Öffnen Sie die Ausgabe
2. Setzen Sie für diesen Datensatz die Option abzugsfähig oder nicht abzugsfähig
3. Prüfen Sie in derselben Ausgabe auch Kategorie und MwSt-Einstellungen
4. Speichern Sie die Ausgabe und nutzen Sie Berichtsfilter, um die erfassten Summen zu sehen

Die App kann diese Einstellung speichern, entscheidet aber nicht, ob eine Ausgabe rechtlich abzugsfähig ist.
