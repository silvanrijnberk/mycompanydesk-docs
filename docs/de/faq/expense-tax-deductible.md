So erfassen Sie die Abzugsfähigkeit in der App:
1. Öffnen Sie die Ausgabe und klicken Sie auf „Bearbeiten“
2. Schalten Sie den Schalter „USt abzugsfähig“ ein oder aus. Schalten Sie ihn aus, wenn Sie den Kauf (auch) privat nutzen
3. Prüfen Sie in derselben Ausgabe auch Kategorie und MwSt-Einstellungen. Manche Kategorien begrenzen den Vorsteuerabzug; das Formular zeigt das dann an
4. Speichern Sie die Ausgabe und nutzen Sie Berichtsfilter, um die erfassten Summen zu sehen

Die App kann diese Einstellung speichern, entscheidet aber nicht, ob eine Ausgabe rechtlich abzugsfähig ist.
