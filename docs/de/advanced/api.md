# API-Integration

MyCompanyDesk bietet keine öffentliche REST API und keine Webhooks für eigene Anbindungen. Sie können also keine API-Schlüssel erstellen und keine Webhooks einrichten.

## Ihre Daten in einem anderen System nutzen

Möchten Sie Ihre Daten anderswo verwenden, geht das in jedem Abonnement auf diese Weise:

- **Daten herunterladen**: Unter **Einstellungen › Daten herunterladen** erhalten Sie Ihre Rechnungen, Kunden und Ausgaben als CSV-Datei pro Bereich oder alles zusammen in einem JSON-Backup. Fotos und PDFs Ihrer Belege sind nicht enthalten; sie bleiben bei der jeweiligen Ausgabe.
- **Ihr Buchhalter**: Geben Sie Ihrem Buchhalter kostenlos Zugang unter **Einstellungen › Ihr Buchhalter**. Dann sieht er immer die neuesten Zahlen, ohne dass Sie Dateien schicken müssen.
