# Affiliate-Programm

Das MyCompanyDesk Affiliate-Programm richtet sich an unabhängige Publisher, Vergleichsportale, Blogs, Newsletter und andere Websites, die eine Vergütung verdienen möchten, indem sie Besucher an MyCompanyDesk verweisen, die ein kostenpflichtiges Abonnement abschließen.

## Für wen

Das Programm steht externen Publishern offen, die relevanten Traffic an MyCompanyDesk senden. Sie benötigen kein MyCompanyDesk-Konto, um teilzunehmen.

## Anmeldung

Melden Sie sich über das Formular auf [mycompanydesk.nl/affiliate](https://mycompanydesk.nl/affiliate) an. Sie geben den Namen Ihrer Website oder Ihres Newsletters, Ihre E-Mail-Adresse, optional Ihre Website und Ihre Themen an. Wir prüfen jede Anmeldung selbst und melden uns innerhalb weniger Werktage, ob Sie dabei sind.

Nach der Freigabe erhalten Sie einen eigenen Link mit Ihrem Code und eine eigene Statistikseite. Eine Anmeldung ist dafür nicht nötig: Die Seite öffnet sich über einen persönlichen Link.

## So funktioniert es

1. Teilen Sie Ihren Link mit Ihrem Publikum. Er führt auf die Website von MyCompanyDesk, damit Besucher sich zuerst in Ruhe umsehen können.
2. Ein Besucher, der über Ihren Link kommt, bleibt für den Rest dieser Browsersitzung Ihrem Code zugeordnet, auch wenn er vor der Registrierung noch einige Seiten liest.
3. Startet der Besucher ein kostenpflichtiges Abonnement, entsteht eine Vergütung für Sie. Eine kostenlose Registrierung bringt nichts ein.

Eine Registrierung über Ihren eigenen Link zählt nicht: Ein Arbeitsbereich mit derselben E-Mail-Adresse wie Ihre Affiliate-Anmeldung bringt keine Vergütung.

## Vergütung und Auszahlung

Sie erhalten einen festen Betrag pro geworbenem Kunden, der ein kostenpflichtiges Abonnement startet. Standardmäßig sind das 40 € pro zahlendem Kunden, ohne Begrenzung der Kundenzahl. Haben Sie eine große Reichweite und möchten eine andere Vergütung vereinbaren, schreiben Sie das in Ihre Anmeldung. Maßgeblich ist der Betrag auf Ihrer Statistikseite.

Eine Vergütung steht zunächst 30 Tage offen. Zahlt der Kunde danach weiter, wird der Betrag auszahlbar. Wir zahlen monatlich per Banküberweisung aus.

## Ihre Statistikseite

Ihre Statistikseite zeigt:

- **Ihr Empfehlungslink**, mit einer Schaltfläche zum Kopieren
- **Besuche**: wie oft jemand über Ihren Link gekommen ist
- **Anmeldungen**: Arbeitsbereiche, die sich über Ihren Link registriert haben
- **Zahlende Kunden**: Arbeitsbereiche, die ein kostenpflichtiges Abonnement gestartet haben
- **Offen**, **Auszahlbar** und **Ausbezahlt**: Ihre Vergütungen nach Status
- **Kürzliche Anmeldungen** mit Datum, Betrag und Status

Daten, mit denen Sie die geworbenen Kunden erkennen könnten, enthält die Seite nicht. Sie sehen, wie viele Kunden über Sie kamen, nicht wer sie sind.

## Status einer Vergütung

- **Offen**: Der Kunde zahlt, und die Wartezeit von 30 Tagen läuft noch
- **Auszahlbar**: Die Wartezeit ist vorbei, und der Kunde zahlt weiterhin
- **Ausbezahlt**: Die Vergütung wurde auf Ihr Bankkonto überwiesen
- **Verfallen**: Der Kunde hat innerhalb der Wartezeit gekündigt, oder die Zahlung wurde vor der Auszahlung erstattet oder zurückgebucht

## Datenschutz und Tracking

Die Zuordnung nutzt nur den Code in Ihrem Link, gespeichert für die Dauer der Browsersitzung. Ein Besuch wird einmal pro Sitzung gezählt und überträgt nur Ihren Code. Der Besucher wird dabei nicht identifiziert, und es werden keine personenbezogenen Daten gespeichert.

## Fragen?

Bei Fragen zum Affiliate-Programm nutzen Sie die Kontaktoptionen auf der [Affiliate-Seite](https://mycompanydesk.nl/affiliate) oder wenden Sie sich an MyCompanyDesk.
