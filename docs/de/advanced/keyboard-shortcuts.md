# Tastenkombinationen

MyCompanyDesk hält die Zahl der Tastenkombinationen bewusst klein. Unten stehen die Kombinationen, die tatsächlich funktionieren.

## Suchfenster

| Tastenkombination | Aktion |
|---|---|
| `Cmd+K` (Mac) / `Strg+K` (Windows/Linux) | Suchfenster öffnen oder schließen |

Das Suchfenster ist der schnellste Weg durch die App:

- Geben Sie mindestens zwei Zeichen ein, um Ihre Kunden, Rechnungen, Ausgaben, Angebote, Aufgaben, wiederkehrende Rechnungen, wiederkehrende Ausgaben, Arbeitsberichte, Katalogartikel, Dokumente und Unterhaltungen im Posteingang zu durchsuchen (plus Projekte, Verträge und Objekte, wenn diese Bereiche aktiviert sind).
- Auch Einstellungen sind durchsuchbar: Tippen Sie zum Beispiel "USt" oder "Erinnerungen", um direkt zur passenden Einstellungskarte zu springen.
- Mit Schnellaktionen springen Sie zu jedem Bereich oder starten eine neue Rechnung, ein Angebot, eine Ausgabe oder einen Kunden.
- Mit den Filter-Chips unter dem Suchfeld begrenzen Sie die Ergebnisse auf einen einzelnen Typ.

Innerhalb des Suchfensters:

| Tastenkombination | Aktion |
|---|---|
| `Pfeil hoch` / `Pfeil runter` | Durch die Ergebnisse bewegen |
| `Enter` | Das markierte Ergebnis öffnen |
| `Esc` | Suchfenster schließen |

## Escape

Mit `Esc` gehen Sie jeweils eine Ebene zurück:

- Beim Tippen in einem Feld wird der Fokus vom Feld entfernt.
- Bei einem geöffneten Dialog wird der Dialog geschlossen.
- Auf einer Detailseite kehren Sie zur Liste zurück (wie mit der Zurück-Schaltfläche).

## Formulare

| Tastenkombination | Aktion |
|---|---|
| `Cmd+S` / `Strg+S` | Formular speichern (bei einer Rechnung ist das **Als Entwurf speichern**) |

Das funktioniert in Formularen mit einer Speicherleiste am unteren Rand, etwa bei Rechnungen, Ausgaben, Arbeitsberichten, Verträgen oder wiederkehrenden Rechnungen. Ist ein Dialog geöffnet, bewirkt die Kombination nichts.

Die üblichen Browser-Tasten funktionieren überall: Mit `Tab` und `Umschalt+Tab` wechseln Sie zwischen Feldern, mit `Enter` senden Sie die meisten Formulare ab.

## Zeitplan

| Tastenkombination | Aktion |
|---|---|
| `A` | **Eintrag hinzufügen** |

Solange Sie in einem Feld tippen, reagiert die Taste nicht.

## Posteingang

Im Posteingang arbeiten Sie mit einzelnen Buchstabentasten, solange Sie nicht in einem Feld tippen:

| Tastenkombination | Aktion |
|---|---|
| `c` | Neue Nachricht |
| `r` | Antworten |
| `j` / `k` | Nächste / vorherige Konversation |
| `e` | Erledigt |
| `s` | Thread mit Stern markieren |
| `u` | Zurück zur Liste |
| `/` | Suche |
| `#` | Löschen |
| `!` | Als Spam markieren |
| `?` | Die Übersicht **Tastenkürzel und Suchfilter** ein- oder ausblenden |

## Website-Editor

Beim Bearbeiten Ihrer Website:

| Tastenkombination | Aktion |
|---|---|
| `Cmd+Z` / `Strg+Z` | Rückgängig |
| `Cmd+Umschalt+Z` / `Strg+Umschalt+Z` oder `Strg+Y` | Wiederholen |
| `Alt+Pfeil hoch` / `Alt+Pfeil runter` | Ausgewählten Block verschieben |
| `Pfeil hoch` / `Pfeil runter` | Vorherigen oder nächsten Block auswählen |
| `Rücktaste` / `Entf` | Ausgewählten Block löschen |
| `Cmd+D` / `Strg+D` | Block duplizieren |
| `Cmd++` / `Cmd+-` (`Strg` unter Windows/Linux) | Hinein- und herauszoomen |
| `Cmd+0` / `Strg+0` | An das Fenster anpassen |
| `Esc` | Auswahl, Bereich oder Vorschau schließen |
| `Cmd+/` / `Strg+/` | Übersicht aller Tastenkombinationen |

Die Übersicht öffnen Sie auch über die Tastatur-Schaltfläche unten in der Seitenleiste des Editors.

Solange ein Textfeld fokussiert ist, wirken Rückgängig und Wiederholen auf den Text, den Sie gerade tippen, und die Pfeiltasten bewegen den Cursor. Klicken Sie zuerst außerhalb des Feldes, um einen ganzen Bearbeitungsschritt zurückzunehmen.
