# Belegscanner

Extrahieren Sie automatisch Ausgabendaten aus Belegbildern und PDF-Rechnungen mit KI-gestützter OCR.

::: info
Der Belegscanner ist in jedem Tarif verfügbar, mit einem monatlichen Limit für die Anzahl der Scans: 3 mit Desk und 200 mit Office. Das Limit wird am Ersten jedes Kalendermonats zurückgesetzt. Sind Ihre Scans aufgebraucht, können Sie den Beleg trotzdem anhängen und die Angaben selbst eintragen.
:::

## Übersicht

Anstatt jede Ausgabe manuell einzugeben, fotografieren Sie einen Beleg oder laden Sie ein PDF hoch und lassen Sie MyCompanyDesk die Details automatisch extrahieren.

## Unterstützte Formate

- **Bilder**: JPEG, PNG und WebP. HEIC-Fotos (Standard auf dem iPhone) funktionieren nicht; machen Sie stattdessen einen Screenshot oder stellen Sie die Kamera auf JPEG um.
- **PDF**: PDF-Rechnungen und Belege, bis zu 15 MB pro Datei. Teilen Sie ein größeres PDF in kleinere Dateien auf.
- **Maximale Dateigröße**: 50 MB. Große Fotos werden vor dem Auslesen automatisch verkleinert.

Eine Gutschrift oder einen Retourenbeleg (negativer Gesamtbetrag) können Sie ganz normal scannen. Die Prüfkarte zeigt eine solche Zeile als Gutschrift mit negativem Betrag, sodass Sie sie sehen, bevor Sie buchen. Nur das automatische Buchen von Belegen aus Ihrem Posteingang überspringt Gutschriften; diese scannen Sie selbst.

::: tip Hinweis zur Dateigröße
Der an die erstellte Ausgabe angehängte Beleg ist auf 10 MB begrenzt. Wenn Sie eine größere Datei scannen, wird die Ausgabe dennoch erstellt, der Beleg aber nicht angehängt; eine Warnung weist Sie darauf hin. Laden Sie anschließend eine kleinere Datei auf der Ausgabe hoch, oder verkleinern Sie das Original vor dem Scan.
:::

## So scannen Sie einen Beleg

Am schnellsten geht es über das normale Ausgabenformular:

1. Gehen Sie zu **Ausgaben** und klicken Sie auf **Hinzufügen**.
2. Wählen Sie **Beleg scannen**, um ein Foto zu machen, oder laden Sie eine Datei hoch (Foto oder PDF).
3. Warten Sie einige Sekunden. Lieferant, Betrag, MwSt. und Datum werden ausgefüllt.
4. Prüfen Sie die Angaben, korrigieren Sie, was nicht stimmt, und speichern Sie die Ausgabe.

Wenn Sie mehrere Zeilen aus einem Dokument übernehmen oder den Scanner steuern möchten, nutzen Sie die Seite **Beleg scannen**. Sie öffnet sich, wenn Sie im vollständigen Ausgabenformular (**Öffnen Sie das vollständige Formular**) unter **Beginnen Sie mit einem Beleg** eine Datei wählen, oder mit Office, wenn Sie im Posteingang bei einem Anhang **Beleg scannen und buchen** wählen. Der Scan startet sofort.

1. Möchten Sie vorher etwas einstellen, klicken Sie nach einem Scan auf **Neuer Scan** und öffnen Sie **Erweiterte Einstellungen**. Wählen Sie unter **Extraktionsmodus**:
   - **Einzelbetrag**: eine Ausgabe für den Gesamtbetrag des Belegs (die Voreinstellung)
   - **Mehrere Posten**: eine Ausgabe pro Zeile desselben Belegs
2. Laden Sie Ihre Belegdatei hoch (Drag-and-Drop oder klicken zum Durchsuchen) und klicken Sie auf **Jetzt scannen**. Der Scanner verarbeitet eine Datei pro Durchgang und ist nach wenigen Sekunden fertig.
3. Überprüfen Sie die erkannten Daten:
   - Datum
   - Betrag
   - Lieferantenname
   - Beschreibung / Positionen
4. Bearbeiten Sie Felder, die korrigiert werden müssen.
5. Klicken Sie auf die Schaltfläche zum Hinzufügen (zum Beispiel **3 Ausgabe(n) hinzufügen**), um die Ausgabe(n) zu erstellen.

## Extraktionsmodi

### Einzelbetrag

Am besten für einfache Belege und die meisten Rechnungen:

- Restaurantrechnungen
- Tankstellenbelege
- Einzelartikelkäufe

Extrahiert: Datum, Gesamtbetrag, Lieferant, Beschreibung.

### Mehrere Posten

Am besten, wenn Sie die Zeilen eines Belegs oder einer Rechnung als einzelne Ausgaben buchen möchten:

- Bürobedarfsbestellungen mit mehreren Artikeln
- Lieferantenrechnungen mit Positionen
- Einkaufslisten

Extrahiert: Einzelne Positionen mit Beschreibungen und Beträgen.

## Erweiterte Einstellungen

Der Scanner hat ein Panel mit erweiterten Optionen:

- **Anweisungen**: Sagen Sie dem Scanner in höchstens 200 Zeichen, worauf er achten oder was er ignorieren soll (z. B. „Nur Tankkosten, Parkgebühren ignorieren“)
- **Extraktionsmodus**: **Einzelbetrag** oder **Mehrere Posten** (Voreinstellung: Einzelbetrag)
- **Ausgabentyp**: Beschränken Sie den Scan auf eine Ausgabenkategorie, oder lassen Sie **Beliebige Kategorie (automatisch)** stehen
- **Nach exakter Übereinstimmung filtern**: Stichwörter; nur Zeilen, deren Beschreibung oder Lieferant zu mindestens einem Stichwort passt, werden übernommen
- **Preisbereich (inkl. MwSt.)**: ein Mindest- und Höchstbetrag; Zeilen außerhalb des Bereichs werden übersprungen
- **Beleg an Ausgaben anhängen**: ob die Originaldatei an jede erstellte Ausgabe angehängt wird (standardmäßig aktiviert)

## Scan-Limits

Belege und Rechnungen mit zu vielen Positionen für einen Durchgang werden mit einer "zu viele Zeilen"-Meldung abgelehnt. Wenn diese Meldung erscheint, teilen Sie das Dokument in kleinere Teile (zum Beispiel eine Seite oder eine kleinere Gruppe von Positionen pro Durchgang) oder erfassen Sie die Ausgaben manuell.

## Tipps für beste Ergebnisse

- **Gute Beleuchtung**: Fotografieren Sie bei guten Lichtverhältnissen
- **Flache Oberfläche**: Legen Sie den Beleg auf eine flache Oberfläche
- **Vollständiger Beleg**: Stellen Sie sicher, dass der gesamte Beleg im Bild ist
- **Klarer Text**: Stellen Sie sicher, dass der Text lesbar und nicht verschwommen ist
- **Ein Beleg pro Scan**: Scannen Sie Belege einzeln für beste Genauigkeit

## Nach dem Scannen

Nach der Bestätigung wird die Ausgabe erstellt mit:

- Allen extrahierten Daten vorausgefüllt
- Dem Originalbeleg als Datei angehängt
- Einer vorgeschlagenen Kategorie und einem MwSt.-Satz; steht dabei, dass sie geschätzt wurden, prüfen Sie sie kurz

Wenn der Scanner ein Lieferantenland ermittelt (zum Beispiel ein ausländischer Lieferant oder eine gematchte niederländische KVK-Nummer), zeigt die Prüfkarte zusätzlich einen Auswahl für die USt-Behandlung. Der Scanner schlägt einen Standardwert auf Basis von Lieferant und Betrag vor, den Sie jedoch vor der Bestätigung ändern können. Das ist wichtig für innergemeinschaftliche Reverse-Charge-Einkäufe und für Importausgaben aus einem Nicht-EU-Land.

Sie können die Ausgabe anschließend wie jede manuell erstellte Ausgabe bearbeiten.

## Währung und Doppelt-Buchungen

Der Scanner erkennt, wenn ein Dokument in einer anderen Währung als Euro ist. In diesem Fall zeigt die Prüfkarte den Originalbetrag mit Währung und ein separates Feld, in dem Sie den Eurobetrag eingeben, wie ihn Ihre Bank umgerechnet hat. Die Zeilen in Fremdwährung können erst bestätigt werden, wenn der Eurobetrag eingetragen ist. Ist das Dokument bereits in Euro, erscheint der Text „Das ist einfach Euro“ und der Ablauf bleibt unverändert.

Wenn der Scanner glaubt, dass ein Beleg bereits gebucht wurde, zeigt er eine Warnung mit Datum, Lieferant und Betrag der bestehenden Ausgabe. Sie können diese Ausgabe öffnen oder den Beleg trotzdem erneut buchen, wenn die Warnung nicht stimmt; das Speichern fragt dann noch einmal, mit „Zweimal dieselbe Ausgabe?“, bevor gebucht wird. Die Prüfung ist eine weiche Absicherung, keine harte Blockade; sie verhindert nur, dass derselbe Beleg aus Versehen zweimal erfasst wird.

Steht für den gescannten Beleg, oder ganz in der Nähe, schon eine Ausgabe in Ihren Büchern, trägt die Prüfkarte den Button **Beleg hier anhängen** (solange diese Ausgabe noch keinen Beleg hat): der Beleg hängt dann als Nachweis an der bestehenden Ausgabe, statt eine zweite zu buchen, die Zeile verschwindet aus der Prüfung, und bei der letzten Zeile landen Sie direkt auf dieser Ausgabe. Eine Ausgabe, die schon einen Beleg hat, bekommt nie einen zweiten darüber.

Zeilen auf demselben Beleg bleiben getrennte Kosten: drei gleiche Parkscheine auf einem Beleg buchen als drei Kosten, und der doppelte Betrag wird markiert, statt stillschweigend übersprungen. Liegt die ganze Ladung schon in Ihren Büchern, sagt die Bestätigung das, statt alles ein zweites Mal zu buchen.

Der Scanner kann auch eigene Verkaufsrechnungen erkennen und warnen, dass das Dokument eher einer Verkaufsrechnung als einer Ausgabe entspricht. Diese Warnung blockiert nicht; Sie können trotzdem fortfahren, wenn es sich um eine Rücksendung oder Korrektur handelt.

## Berechtigungen

Der Belegscanner unterliegt derselben Seitenberechtigung wie die Seite Ausgaben. Ein Teammitglied braucht **Lesen**-Zugriff auf Ausgaben, um den Scanner zu öffnen, und **Erstellen**-Zugriff, um einen gescannten Beleg als neue Ausgabe zu bestätigen. Mitglieder ohne Erstellen-Berechtigung sehen den Scanner weiterhin, können die Bestätigung aber nicht abschließen. Das gilt sowohl für Uploads über die Seite Ausgaben als auch für geteilte Fotoflows.

## Mehrere Belege scannen

Der Uploader verarbeitet eine Datei pro Durchgang. Um mehrere Belege zu verarbeiten, scannen Sie sie nacheinander; jeder Scan zählt einmal für Ihr monatliches Limit. Für einen Beleg oder eine Rechnung mit mehreren Positionen wählen Sie **Mehrere Posten**, um mit einem Scan mehrere Ausgaben zu erstellen.

## Tipps

- Scannen Sie Belege sofort nach Erhalt und lassen Sie sie sich nicht ansammeln
- Überprüfen Sie den extrahierten Betrag sorgfältig, besonders bei Belegen mit mehreren Währungen
- Bewahren Sie die Original-Belegdatei als Anhang für Steuerprüfungszwecke auf
- Prüfen Sie bei Belegen in Fremdwährung immer, ob der Eurobetrag mit der Umrechnung Ihrer Bank übereinstimmt
- Zweifeln Sie an einer Doppelt-Buchungsmeldung? Öffnen Sie die bestehende Ausgabe, um sicherzugehen
