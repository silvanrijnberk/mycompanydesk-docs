# Newsletter

Versenden Sie E-Mail-Kampagnen an Ihre Abonnenten von Ihrer eigenen verifizierten Domain aus. Die Newsletter-Seite zeigt Ihre Kampagnen, Ihre Abonnentenliste und die Ergebnisse pro Empfänger nach dem Versand.

## Was Sie tun können

- Erstellen Sie Newsletter in einem Drag-and-Drop-Editor mit Hero-, Text-, Bild-, Button- und Footer-Blöcken.
- Fügen Sie Betreff, Vorschautext und Merge-Tags wie `{{ first_name }}`, `{{ name }}` und `{{ email }}` hinzu, damit jeder Empfänger eine personalisierte Nachricht erhält.
- Senden Sie vor dem Broadcast eine Test-E-Mail.
- Senden Sie sofort oder planen Sie eine Kampagne für einen späteren Zeitpunkt.
- Verwalten Sie Abonnenten: fügen Sie sie manuell hinzu, importieren Sie eine Liste, übernehmen Sie sie aus Ihrer Kundenliste oder exportieren Sie die Liste.
- Prüfen Sie pro Empfänger Öffnungen, Klicks, Zustellungen, Bounces, Abmeldungen und Fehler.

## Aufruf

Öffnen Sie die Newsletter-Seite über die Hauptnavigation. Für Ihren Arbeitsbereich muss das Newsletter-Feature aktiviert sein.

## Abonnenten

Das Tab Abonnenten zeigt alle Personen, die Ihre Newsletter erhalten können.

Jeder Abonnent hat einen dieser Status:

- **Aktiv** — erhält zukünftige Kampagnen.
- **Ausstehend** — hat das Opt-in noch nicht bestätigt.
- **Abgemeldet** — hat sich abgemeldet und erhält keine Kampagnen mehr.
- **Unzustellbar** — Zustellung ist mehrfach fehlgeschlagen; Versand an diese Adresse wird gestoppt.

Sie können einen einzelnen Abonnenten hinzufügen, eine Liste mit E-Mail-Adressen einfügen, Abonnenten aus Ihrer Kundenliste importieren oder die gesamte Liste exportieren. Importierte oder manuell hinzugefügte Adressen müssen das Einverständnis haben, Ihre E-Mails zu erhalten.

## Eine Kampagne erstellen

1. Gehen Sie zum Tab Kampagnen und klicken Sie auf **Neue Ausgabe** (oder starten Sie den Assistenten).
2. Geben Sie einen Betreff und einen Vorschautext ein. Der Vorschautext erscheint unter dem Betreff in vielen Posteingängen.
3. Bauen Sie den Inhalt mit Blöcken auf. Verwenden Sie einen Hero-Block für eine Überschrift, und fügen Sie Text, Bilder und einen Call-to-Action-Button hinzu.
4. Überschreiben Sie bei Bedarf den Footer-Text; andernfalls verwendet die App die Absenderadresse aus Ihren Newsletter-Einstellungen.
5. Senden Sie einen Test an sich selbst oder einen Kollegen, und klicken Sie auf **Senden**, wenn Sie bereit sind. Ein Bestätigungsdialog zeigt, wie viele aktive Abonnenten die Nachricht erhalten.

Kampagnen können auch eingeplant werden. Eingeplante Kampagnen bleiben bis zum geplanten Zeitpunkt gesperrt; heben Sie die Planung auf, wenn Sie noch etwas bearbeiten möchten.

## Ergebnisse pro Empfänger

Nachdem eine Kampagne versendet wurde, öffnen Sie die Ergebnisseite, um zu sehen, was mit jeder Adresse passiert ist. Oben sehen Sie die Gesamtwerte:

- **Versendet** — wir haben die Nachricht an Ihren Versanddienstleister übergeben.
- **Zugestellt** — der Dienstleister hat bestätigt, dass das Postfach sie akzeptiert hat.
- **Unzustellbar** — das Postfach hat sie abgelehnt oder die Adresse ist nicht erreichbar.
- **Geöffnet** — der Empfänger hat die E-Mail mindestens einmal geöffnet.
- **Geklickt** — der Empfänger hat auf einen Link in der E-Mail geklickt.
- **Abgemeldet** — der Empfänger hat den Abmeldelink verwendet.
- **Fehlgeschlagen** — die Kampagne konnte an diese Adresse nicht versendet werden.

Unter den Gesamtwerten finden Sie die Liste aller Empfänger. Sie können nach Name oder E-Mail-Adresse suchen. Jede Zeile zeigt den Hauptstatus für diese Adresse, zum Beispiel Versendet, Zugestellt, Geöffnet, Unzustellbar oder Fehlgeschlagen.

### Versendet versus Zugestellt

Eine Nachricht mit dem Status **Versendet** hat unser System verlassen. Sie wird erst **Zugestellt**, wenn Ihr E-Mail-Anbieter zurückmeldet, dass das Postfach sie akzeptiert hat. Manche Anbieter oder Versandwege liefern diese Rückmeldung nicht. In diesem Fall zeigt die Seite einen Hinweis, dass die Nachricht jedem Empfänger übergeben wurde, aber noch nicht bekannt ist, ob das Postfach sie angenommen hat.

Dieser Unterschied ist wichtig für ältere Kampagnen, die vor der Einführung der Rückmeldung versendet wurden, und für Wege ohne verfügbare Telemetrie. Die App meldet nie etwas als zugestellt ohne Beweis.

## Bevor Sie senden können

Newsletter erfordern einige Einstellungen:

- Ihre eigene verifizierte Domain für den Versand. Kampagnen gehen nie von mycompanydesk.com aus.
- Eine physische Postadresse im Footer, die für kommerzielle E-Mail gesetzlich vorgeschrieben ist.
- Ein Absendername und eine Antwort-Adresse, damit Leser wissen, wer die E-Mail sendet, und Antworten in Ihrem Posteingang landen.

Der Editor leitet Sie zur passenden Einstellungsseite weiter, falls etwas fehlt.
