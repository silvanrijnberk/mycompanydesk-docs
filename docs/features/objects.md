# Objects & assets

MyCompanyDesk keeps all company assets in one place: real estate, vehicles, machines, inventory and other possessions. You can track ownership, value, rental income, linked contracts and related invoices per object.

## Creating an object

1. Go to **Instellingen** > **Objecten**.
2. Click **Nieuw object** and choose a type:
   - **Property** - buildings and land
   - **Vehicle** - cars, vans, trucks and similar
   - **Machine / installation** - equipment used in the business
   - **Inventory** - office or shop furnishings
   - **Other** - any other asset
3. Fill in the required fields: at minimum a name, optionally a description, purchase date/value and status.
4. Save.

The object is now available to link to contracts, invoices, expenses and time entries.

## Object detail page

The detail page shows all information for an object at a glance:

- Asset information and type
- Current status
- **Total revenue**: real paid-invoice revenue for this object, including rent, service charges, one-off charges and sale invoices attributed to it
- **Active contracts**: number of currently active contracts linked to this object (only shown when the object has contracts or is real estate)
- **WOZ history** (for Properties) - annual WOZ values used in the Box 3 tax calculation
- **Asset summary** (for Property objects with a recorded WOZ value) - capitalized value, accumulated depreciation, current book value and the legal floor (bodemwaarde) for the building
- Linked contracts and rental history (shown when relevant)
- **Invoices**: every invoice that counts toward total revenue, with status and amount excluding VAT (only shown when the object has invoices or is real estate)
- **Mileage log** (for Vehicle objects with trips) - the trips driven in this vehicle, total kilometres, breakdown per year and recent trips

The page hides cards that do not match the asset type. Default rent, WOZ history and an empty address card only appear for real estate or when the object actually carries that data. Contracts and invoices cards stay hidden for vehicles, machines and other non-property assets until there is data to show, so the page stays focused on the asset you are viewing.

### Invoices attributed to this object

Every invoice line that is attributed to the object is listed here. This gives a clear picture of the actual paid revenue generated by the asset.

The total counts paid invoices only, not draft or open invoices. This keeps the revenue figure aligned with what is actually received.

### Contract summary header

At the top of the page you see a summary of the active contracts for this object:

- Number of active contracts
- Current monthly rent
- Next indexation date
- Contract end date of the nearest ending contract

This gives a quick financial snapshot without opening each contract separately.

### WOZ history and bodemwaarde

For **Property** objects you can register the annual WOZ value. This value is used for the Box 3 (wealth tax) calculations in your bookkeeping.

The page also shows the **bodemwaarde** (legal floor value). For buildings, the tax value cannot be lower than this floor. MyCompanyDesk uses the WOZ value, the floor and the purchase date to determine the correct value for tax reporting.

This rule applies to buildings only. Vehicles, machines, inventory and other assets do not have a bodemwaarde floor.

### Vehicle mileage log (Vehicle objects)

Vehicle objects that are used for work trips show a **Mileage log** card once they have at least one linked trip. This is the trip record the tax office expects for a company vehicle: it lists the trips that were driven in this vehicle, not the running costs of the vehicle.

The card shows:

- **Total kilometres** driven in this vehicle
- **Current year** kilometres, if the vehicle was driven this calendar year
- **Number of trips**
- **Last trip** date
- A **per-year** breakdown of kilometres and trip counts
- The most recent trips, with origin, destination, date and customer

Only the most recent trips are shown at first. If there are more, a **Show older trips** button reveals the rest, so the list is never silently cut.

A trip is linked to the vehicle when the travel entry selects it as the company vehicle. That trip does not receive a separate kilometre reimbursement, because its real costs (fuel, maintenance and depreciation) are already tracked through expenses on the object.

### Asset summary and bodemwaarde

The asset summary shows the financial picture of a property in the ledger:

- Capitalized value
- Accumulated depreciation
- Current book value
- Legal floor (bodemwaarde)

These figures are needed for the annual balance sheet and tax reporting.

This section only appears for **Property** objects with a recorded WOZ value. Vehicles, machines, inventory and other assets do not have a bodemwaarde and therefore do not show this summary.

### Disposal

When an asset is sold or scrapped, you can record the disposal:

1. Open the object.
2. Choose **Verwijderen / Verkocht** (remove / sold) under the disposal section.
3. Enter the disposal date and sale proceeds.
4. Save.

MyCompanyDesk then calculates the capital gain or loss and includes it in the financial administration.

### Contract signing status

For each active contract you can see whether the digital signing process has been completed. The object page lists:

- Contract parties
- Start and end dates
- Signature status
- Monthly rent

Click a contract to open it in full detail.

### Linking objects

Objects can be linked to:

- **Contracts** - rental and lease contracts
- **Invoices** - rent, service charges and sales
- **Expenses** - maintenance and operating costs
- **Time entries** - travel and work done on or with the object

Open the relevant document and select the object from the object picker. The link is stored in both places, so you can navigate from the object to the document and back.

## Object types and their fields

| Type | Typical fields |
|------|----------------|
| Property | Address, WOZ value, bodemwaarde, rental details, purchase value |
| Vehicle | Licence plate, purchase value, default rent, status, mileage log |
| Machine / installation | Description, purchase value, status, depreciation |
| Inventory | Description, purchase value, status |
| Other | Description, purchase value, status |

Each type has only the fields that are relevant for that kind of asset. For example, a WOZ value is not shown for a vehicle, and a licence plate is not shown for a machine.

## Where to find objects

- **Instellingen** > **Objecten** - list of all objects and assets
- **Menu** > **Objecten** - quick access when the menu item is enabled in your role
- Linked from contracts, invoices, expenses and time entries
