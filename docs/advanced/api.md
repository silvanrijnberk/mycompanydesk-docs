# API-integratie

MyCompanyDesk biedt geen publieke REST API en geen webhooks voor eigen koppelingen. Je kunt dus geen API-sleutels aanmaken en geen webhooks instellen.

## Je gegevens in een ander systeem gebruiken

Wil je je gegevens ergens anders gebruiken, dan kan dat op elk abonnement op deze manieren:

- **Gegevens downloaden**: onder **Instellingen › Gegevens downloaden** haal je je facturen, klanten en uitgaven op als CSV-bestand per onderdeel, of alles samen in één JSON-back-up. De foto's en pdf's van je bonnetjes zitten er niet in; die bewaar je bij de uitgave zelf.
- **Je boekhouder**: geef je boekhouder gratis toegang onder **Instellingen › Je boekhouder**. Dan kijkt die altijd naar de nieuwste cijfers, zonder dat je bestanden hoeft door te sturen.
