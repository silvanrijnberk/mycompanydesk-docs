# API Integration

MyCompanyDesk does not offer a public REST API or webhooks for your own integrations. That means you cannot create API keys or set up webhooks.

## Using your data in another system

If you want to use your data elsewhere, you can do so on every plan in these ways:

- **Download data**: under **Settings › Download data** you get your invoices, customers and expenses as a CSV file per section, or everything together in one JSON backup. Photos and PDFs of your receipts are not included; they stay with the expense itself.
- **Your accountant**: give your accountant free access under **Settings › Your accountant**. They then always look at your latest figures, without you having to send files.
