# Keyboard Shortcuts

MyCompanyDesk keeps its set of keyboard shortcuts deliberately small. The shortcuts below are the ones that work today.

## Search palette

| Shortcut | Action |
|---|---|
| `Cmd+K` (Mac) / `Ctrl+K` (Windows/Linux) | Open or close the search palette |

The search palette is the fastest way to move around the app:

- Type at least two characters to search your customers, invoices, expenses, quotes, tasks, recurring invoices, recurring expenses, work orders, catalog items, documents, and inbox conversations (plus projects, contracts, and assets when those features are enabled).
- Settings are searchable too: type something like "VAT" or "reminders" to jump straight to the matching settings card.
- Quick actions let you jump to any section or start a new invoice, quote, expense, or customer.
- Filter chips under the search box narrow results to a single type.

Inside the palette:

| Shortcut | Action |
|---|---|
| `Up` / `Down` | Move through the results |
| `Enter` | Open the highlighted result |
| `Esc` | Close the palette |

## Escape

`Esc` steps back one level at a time:

- While typing in a field, it removes focus from that field.
- With a dialog open, it closes the dialog.
- On a detail page, it takes you back to the list (the same as the back button).

## Forms

| Shortcut | Action |
|---|---|
| `Cmd+S` / `Ctrl+S` | Save the form (on an invoice this is **Save as Draft**) |

This works in forms with a save bar at the bottom, such as an invoice, expense, work order, contract or recurring invoice. While a dialog is open, the shortcut does nothing.

Standard browser keys work everywhere: `Tab` and `Shift+Tab` move between fields, and `Enter` submits most forms.

## Schedule

| Shortcut | Action |
|---|---|
| `A` | **Add Entry** |

The shortcut does not fire while you are typing in a field.

## Inbox

The inbox uses single-letter keys, as long as you are not typing in a field:

| Shortcut | Action |
|---|---|
| `c` | New message |
| `r` | Reply |
| `j` / `k` | Next / previous conversation |
| `e` | Done |
| `s` | Star this thread |
| `u` | Back to list |
| `/` | Search |
| `#` | Delete |
| `!` | Mark as spam |
| `?` | Show or hide the **Shortcuts and search filters** overview |

## Site builder

While editing your website:

| Shortcut | Action |
|---|---|
| `Cmd+Z` / `Ctrl+Z` | Undo |
| `Cmd+Shift+Z` / `Ctrl+Shift+Z` or `Ctrl+Y` | Redo |
| `Alt+Up` / `Alt+Down` | Move the selected block |
| `Up` / `Down` | Select the previous or next block |
| `Backspace` / `Delete` | Delete the selected block |
| `Cmd+D` / `Ctrl+D` | Duplicate the block |
| `Cmd++` / `Cmd+-` (`Ctrl` on Windows/Linux) | Zoom in and out |
| `Cmd+0` / `Ctrl+0` | Fit to the window |
| `Esc` | Close the selection, panel or preview |
| `Cmd+/` / `Ctrl+/` | Overview of all shortcuts |

You can also open the overview with the keyboard button at the bottom of the editor's side rail.

While a text field is focused, undo and redo apply to the text you are typing and the arrow keys move the cursor. Click outside the field first to undo a whole editing step.
