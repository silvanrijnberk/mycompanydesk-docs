To view charts and graphs:
1. Go to **Reports** in the sidebar (Office)
2. Open one of the tabs, for example **Overview**, **Sales**, **Clients**, **Expenses** or **Cash Flow**
3. The charts are built into each tab; there is no separate Charts section
4. Use **Filters** to adjust the time period

The **Figures** page in the sidebar also has a 12-month trend chart and a cash chart.

Tip: Always confirm the active filters first when chart values seem off.
