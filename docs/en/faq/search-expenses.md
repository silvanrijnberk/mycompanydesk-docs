To search and filter expenses:
1. Go to Expenses
2. Use the search bar to find by supplier or description
3. Narrow down under **Filters** by category or status (Paid or Unpaid), or show only expenses where the receipt or the VAT is missing
4. Sort by date, supplier, category, status, or amount

Combine the search bar with the category filter when the list is long.
