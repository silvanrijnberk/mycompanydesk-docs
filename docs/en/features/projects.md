# Projects

Organize your work into projects to track time, revenue, and profitability per engagement.

## Overview

Projects help you group invoices, expenses, and time entries together. This gives you a clear picture of how profitable each project or client engagement is.

## Creating a project

1. Go to **Projects › New project**
2. Fill in:
   - **Name**: a clear project name (the only required field)
   - **Customer**: the client this project is for
   - **Description**: what the project involves
   - **Budget**: an optional budget amount
   - **Status**: Planned, Active, Paused or Completed
3. Click **Save**

## Project statuses

| Status | Description |
|---|---|
| **Planned** | Not started yet |
| **Active** | Currently being worked on |
| **Paused** | Temporarily on hold |
| **Completed** | Finished, no more work expected |
| **Cancelled** | Not going ahead |

A project you no longer want in your list can be archived. It then sits in the **Archive** view; deleted projects sit in the **Trash**.

## Project detail page

The project detail page shows:

- **What this project delivers**: income, expenses and the result
- **Budget**: how much has been spent and what is left
- **Hours per person**: who logged how many hours on the project
- **History**: the invoices, expenses and hours linked to the project
- **Automatic invoicing**: how the project's hours are invoiced (see below)

## Linking items to projects

When creating invoices, expenses, or time entries, select the project from the dropdown to link them. This automatically updates the project's financials.

- **Invoices**: Track revenue per project
- **Expenses**: Track costs per project
- **Time entries**: Track hours per project

## Linking to a contract

When you create or edit a project, you can link it to a contract in the **Contract** field. Hours you log on the project are included on that contract's invoice.

This is useful when the contract sets the rate (hourly, daily or fixed project price) and the project supplies the work. Invoices for the contract pick up the logged hours automatically.

If a contract has no rate set, hours linked to it stay uninvoiced and you get a notification telling you they could not be priced.

## Automatic billing for a project

A project can invoice its hours on a rhythm of its own. On the project page you pick under **Automatic invoicing** how it is invoiced:

- **Manual** (the default): you create the invoice yourself, from the project's hours.
- **On a fixed day**: every week or every month on the day you choose, the hours and charged expenses up to then go on an invoice for the customer.
- **When completed**: everything still open goes on a final invoice once you set the project to Completed.

You can also switch on **On its own invoice**, so the project does not share an invoice with the other projects of the same customer. The customer's page holds the [full overview](/en/features/time-registration#automatic-time-invoicing): all projects of that customer, the hours without a project, and how sending works.

Projects and time tracking are included in every plan, Desk too. Automatic invoicing is part of Office; on Desk you create the invoice yourself from the hours.

## Budget tracking

If you set a budget:

- See how much of the budget has been spent
- See how much budget is left
- The project list shows an **Over budget** label as soon as costs pass the budget

## Bulk actions

Select several projects in the list:

- **Archive**: move projects to the archive
- **Delete**: move projects to the trash
- **Restore**: bring projects back from the archive or the trash

## Profitability

The project list shows the income, expenses, net result and margin per project. On **Figures**, the **Project margins** block compares your projects with each other.

## Tips

- Use projects for short engagements too: the insights are valuable
- Link both invoices and expenses to get accurate profit margins
- Archive completed projects to keep your active list clean
