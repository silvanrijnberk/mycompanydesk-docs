# Infolettres

> **Statut : en développement actif.** Les infolettres sont masquées derrière le feature flag `newsletters`. Activez-les dans Paramètres > Modules.

L'éditeur d'infolettres vous aide à rédiger, planifier et envoyer des campagnes à vos clients. Il est lié à votre liste de clients, donc les destinataires restent synchronisés sans importer de fichier CSV.

## Où le trouver

Activez la fonctionnalité dans **Paramètres > Modules**, puis ouvrez **Infolettres** dans le menu principal.

La page comporte trois onglets :

- **Campagnes** - brouillons, envois planifiés et campagnes envoyées.
- **Aperçu** - les chiffres clés des campagnes récentes.
- **Abonnés** - le public qui reçoit vos infolettres.

Vous avez besoin des droits d'administrateur de l'espace de travail pour activer ou désactiver la fonctionnalité.

## Liste des campagnes

Chaque campagne apparaît sur une ligne unique avec :

- une icône colorée qui reflète l'état de la campagne
- l'objet, ou *pas d'objet* si le brouillon est encore vide
- une ligne de métadonnées avec l'horodatage pertinent
- un badge d'état (brouillon, planifié, envoi en cours, envoyé, annulé ou échoué)
- une petite jauge montrant le taux d'ouverture dès qu'une campagne est envoyée
- une action principale : **Modifier** pour les brouillons, **Voir** pour les envois envoyés ou planifiés
- des actions supplémentaires dans le menu débordant, notamment **Résultats**, **Renvoyer** et **Supprimer**

Survolez la ligne pour afficher le menu débordant sur ordinateur. Sur mobile, le menu est toujours visible.

## Créer une campagne

Il existe deux points d'entrée :

- **Nouvelle infolettre** dans l'en-tête de page crée un brouillon vide.
- **Créer avec l'IA** lance l'assistant IA, qui transforme une courte consigne en une première version de votre envoi.

Les deux aboutissent dans l'éditeur de campagne, où vous pouvez modifier l'objet, le pré-en-tête, le contenu, l'expéditeur et le public avant d'envoyer ou de planifier.

## Envoyer et planifier

- **Envoyer maintenant** met la campagne immédiatement en file d'attente.
- **Planifier** vous permet de choisir une date et une heure futures.
- **Enregistrer le brouillon** enregistre la campagne sans l'envoyer.

Une fois qu'une campagne est en file d'attente ou envoyée, elle ne peut plus être supprimée ; une campagne échouée peut être renvoyée depuis le menu débordant.

## Résultats

Ouvrez l'action **Résultats** d'une campagne envoyée, en cours d'envoi ou échouée pour voir les données de livraison et d'ouverture par destinataire. L'onglet Aperçu agrège ces chiffres au niveau de l'espace de travail.
