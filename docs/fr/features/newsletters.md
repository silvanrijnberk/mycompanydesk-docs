# Newsletters

Envoyez des campagnes par e-mail à vos abonnés depuis votre propre domaine vérifié. La page Newsletters affiche vos campagnes, votre liste d'abonnés et le résultat par destinataire après l'envoi.

## Ce que vous pouvez faire

- Composez des newsletters dans un éditeur glisser-déposer avec des blocs hero, texte, image, bouton et pied de page.
- Ajoutez un objet, un texte d'aperçu et des balises de fusion comme `{{ first_name }}`, `{{ name }}` et `{{ email }}`, pour que chaque destinataire reçoive un message personnalisé.
- Envoyez un e-mail de test avant de lancer la campagne.
- Envoyez immédiatement ou planifiez une campagne pour une date et une heure ultérieures.
- Gérez les abonnés : ajoutez-les manuellement, importez une liste, copiez-les depuis votre liste de clients ou exportez la liste.
- Consultez, par destinataire, les ouvertures, clics, distributions, rejets, désabonnements et échecs.

## Accès

Ouvrez la page Newsletters depuis la navigation principale. Votre espace de travail doit avoir la fonctionnalité newsletter activée.

## Abonnés

L'onglet Abonnés affiche toutes les personnes qui peuvent recevoir vos newsletters.

Chaque abonné a l'un des statuts suivants :

- **Actif** — recevra les campagnes futures.
- **En attente** — n'a pas encore confirmé son opt-in.
- **Désabonné** — s'est désabonné et ne recevra plus de campagnes.
- **Non distribué** — la livraison a échoué plusieurs fois ; l'envoi vers cette adresse s'arrête.

Vous pouvez ajouter un seul abonné, coller une liste d'adresses e-mail, importer des abonnés depuis votre liste de clients ou exporter la liste complète. Les adresses importées ou ajoutées manuellement doivent avoir consenti à recevoir vos e-mails.

## Créer une campagne

1. Allez dans l'onglet Campagnes et cliquez sur **Nouveau numéro** (ou démarrez avec l'assistant).
2. Saisissez un objet et un texte d'aperçu. Le texte d'aperçu apparaît sous l'objet dans de nombreuses boîtes de réception.
3. Construisez le contenu avec des blocs. Utilisez un bloc hero pour un titre, et ajoutez du texte, des images et un bouton d'appel à l'action.
4. Remplacez éventuellement le texte du pied de page ; sinon, l'application utilise l'adresse d'expéditeur enregistrée dans vos paramètres newsletter.
5. Envoyez un test à vous-même ou à un collègue, puis cliquez sur **Envoyer** quand vous êtes prêt. Une boîte de confirmation indique le nombre d'abonnés actifs qui recevront le message.

Les campagnes peuvent aussi être planifiées. Les campagnes planifiées restent verrouillées jusqu'au moment prévu ; annulez la planification si vous devez encore modifier quelque chose.

## Résultat par destinataire

Après l'envoi d'une campagne, ouvrez la page de résultats pour voir ce qui s'est passé pour chaque adresse. En haut figurent les chiffres agrégés :

- **Envoyé** — nous avons remis le message à votre fournisseur d'envoi.
- **Distribué** — le fournisseur a confirmé que la boîte aux lettres l'a accepté.
- **Non distribué** — la boîte aux lettres l'a refusé ou l'adresse est injoignable.
- **Ouvert** — le destinataire a ouvert l'e-mail au moins une fois.
- **Cliqué** — le destinataire a cliqué sur un lien de l'e-mail.
- **Désabonné** — le destinataire a utilisé le lien de désabonnement.
- **Échec** — la campagne n'a pas pu être envoyée à cette adresse.

Sous les totaux se trouve la liste de tous les destinataires. Vous pouvez rechercher par nom ou adresse e-mail. Chaque ligne affiche le statut principal de cette adresse, par exemple Envoyé, Distribué, Ouvert, Non distribué ou Échec.

### Envoyé versus Distribué

Un message marqué **Envoyé** est sorti de notre système. Il ne devient **Distribué** que lorsque votre fournisseur d'e-mail confirme que la boîte aux lettres l'a accepté. Certains fournisseurs ou circuits d'envoi ne transmettent pas cette confirmation. Dans ce cas, la page affiche une note expliquant que le message a été remis au fournisseur pour chaque destinataire, mais qu'il n'est pas encore connu si la boîte aux lettres l'a accepté.

Cette distinction importe pour les campagnes plus anciennes envoyées avant l'ajout du suivi, ainsi que pour les circuits où aucune télémétrie n'est disponible. L'application ne rapporte jamais un message comme distribué sans preuve.

## Avant de pouvoir envoyer

Les newsletters nécessitent quelques paramètres :

- Votre propre domaine vérifié pour l'envoi. Les campagnes ne partent jamais de mycompanydesk.com.
- Une adresse postale physique dans le pied de page, obligatoire par la loi pour les e-mails commerciaux.
- Un nom d'expéditeur et une adresse de réponse, pour que les lecteurs sachent qui envoie l'e-mail et que les réponses arrivent dans votre boîte de réception.

L'éditeur vous dirige vers la page de paramètres appropriée si quelque chose manque.
