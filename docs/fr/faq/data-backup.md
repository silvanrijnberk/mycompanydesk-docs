Pour sauvegarder vos données :
1. Allez dans Paramètres › « Télécharger les données »
2. Téléchargez les exports CSV pour les factures, les clients et les dépenses, ou la sauvegarde complète disponible à cet endroit
3. Pour une copie complète, utilisez **Tout télécharger** sur la même page : un ZIP avec les PDF de vos factures, devis, bons de travail et contrats, vos justificatifs, documents, e-mails, votre site et vos déclarations de TVA, plus un fichier d'audit par année. Vous recevez un e-mail dès qu'il est prêt ; la propriétaire ou le propriétaire, ou un admin, peut le demander une fois par jour
4. Vérifiez que les fichiers téléchargés contiennent bien les enregistrements dont vous avez besoin

Les exports CSV des factures, des dépenses et de votre liste de clients, ainsi que la sauvegarde complète, sont gratuits sur tous les plans. Si vous sauvegardez régulièrement, choisissez un moment fixe, par exemple après la clôture de chaque trimestre.
