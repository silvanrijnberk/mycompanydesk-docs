Vous utilisez MyCompanyDesk sur votre téléphone avec l'application ou dans votre navigateur mobile.

**Avec l'application**
1. Installez l'application MyCompanyDesk depuis Google Play (Android) ou l'App Store (iPhone)
2. Connectez-vous avec le même compte que sur votre ordinateur
3. Activez les notifications push si vous voulez être prévenu dès qu'il se passe quelque chose, voir [Paramètres de notification](/fr/faq/notification-settings)

**Dans votre navigateur**
1. Ouvrez votre navigateur mobile (Chrome, Safari, etc.)
2. Allez sur [app.mycompanydesk.com](https://app.mycompanydesk.com)
3. L'interface s'adapte automatiquement à la taille de votre écran
4. Vous pouvez l'ajouter à votre écran d'accueil pour un accès rapide

Astuce : toutes les fonctionnalités sont disponibles sur mobile, vous créez donc des factures, enregistrez des dépenses et gérez vos clients en déplacement.
