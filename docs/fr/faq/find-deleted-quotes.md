Les devis supprimés se trouvent dans Devis : cliquez sur Filtres au-dessus de la liste et choisissez la vue Corbeille sous Afficher. Sur votre téléphone, utilisez le bouton de filtre en haut. Les devis archivés se trouvent dans les Archives.
