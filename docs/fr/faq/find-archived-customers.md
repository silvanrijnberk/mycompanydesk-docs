Les clients archivés se trouvent dans Clients : cliquez sur Filtres au-dessus de la liste et choisissez la vue Archives sous Statut. Sur votre téléphone, utilisez le bouton de filtre en haut. Les clients supprimés se trouvent dans la Corbeille.
