Pour ajouter, modifier ou supprimer des lignes sur une facture :
1. Ouvrez la facture en mode édition
2. Cliquez sur « Ajouter une ligne » ou le bouton + pour ajouter une nouvelle ligne
3. Saisissez la description, la quantité, le prix unitaire et le taux de TVA. Le champ de description est la porte vers votre catalogue : cliquez dans le champ vide (ou appuyez sur la flèche vers le bas) pour voir votre catalogue d'emblée, ou commencez à taper et les articles qui correspondent apparaissent en dessous. En choisir un remplit la ligne avec sa description, son prix et son taux de TVA
4. Entrée garde votre propre texte ; pour choisir une suggestion, cliquez dessus ou naviguez avec les flèches et Entrée
5. Un texte plus long ? Dans un nouveau document, quand la première (seule) ligne décrit tout un travail en six mots ou plus et que l'IA est activée, la liste propose **Créer des lignes à partir de ce texte** : la phrase devient des lignes avec prix, depuis votre catalogue si possible
6. Une ligne tapée vous-même, avec description et un prix au-dessus de zéro, montre **Enregistrer dans votre catalogue** en dessous, pour que votre catalogue grandisse pendant que vous facturez
7. Pour supprimer une ligne, cliquez sur l'icône de suppression (×) de cette ligne
8. Pour réorganiser, glissez-déposez les lignes
9. Enregistrez lorsque vous avez terminé

Les mêmes suggestions sous le champ de description existent aussi pour les lignes de devis et les factures récurrentes.

Astuce : Utilisez des descriptions de lignes claires et détaillées pour des factures professionnelles.
