Pour supprimer votre compte :
1. Téléchargez d'abord vos données via Paramètres → "Télécharger les données" si vous souhaitez en garder une copie
2. Allez dans Paramètres → "Résilier le compte"
3. Sous "Supprimer définitivement le compte", cliquez sur "Supprimer"
4. Confirmez avec votre mot de passe actuel. Vous vous connectez avec Google, Microsoft ou Apple, et il n'y a pas de champ mot de passe ; vous confirmez sans.

Ensuite, cela dépend de votre rôle :

- **Pas propriétaire d'un espace de travail** : votre compte et toutes vos données personnelles sont effacés définitivement. Vous vous connectez via Google, Microsoft ou Apple sans avoir défini de mot de passe ? L'application vous demande d'abord d'en définir un dans Paramètres > Profil ; ensuite la suppression fonctionne ici comme d'habitude.
- **Propriétaire d'un espace de travail** : votre compte et l'espace de travail vont ensemble, et l'effacement de la comptabilité relève du support, avec les obligations de conservation et un export préalable comme questions ouvertes. Le bouton dépose alors une demande auprès du support : vous recevez un accusé de réception par e-mail et le support vous contacte pour finaliser. Une demande ouverte par semaine ; renouveler le clic ne crée pas de seconde demande.

Sur la même page, vous pouvez aussi résilier uniquement votre abonnement payant. Vous ne payez alors plus rien, mais votre compte et vos données sont conservés, car la législation fiscale néerlandaise impose de garder votre comptabilité pendant 7 ans. Avant que vous ne confirmiez, la page liste ce qui continue de fonctionner et ce qui s'arrête, pour que vous sachiez ce que vous choisissez. Si vous supprimez votre compte, votre compte et toutes vos données disparaissent définitivement.

Important : la suppression du compte est irréversible. Exportez tout ce dont vous avez besoin avant de continuer.
