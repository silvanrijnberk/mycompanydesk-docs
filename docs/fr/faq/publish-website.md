# Publier votre site web et le mettre en ligne

Votre site web n'est en ligne qu'une fois publié. Jusque-là, vous voyez vos modifications dans l'éditeur, mais pas vos visiteurs.

## Comment publier mon site web ?

1. Dans le menu de gauche, cliquez sur **Site web**.
2. Cliquez sur **Modifier le site**. L'éditeur s'ouvre.
3. Modifiez vos textes, photos et pages. Tout est enregistré automatiquement.
4. En haut à droite, cliquez sur **Publiceer** (publier), puis sur **Publiceer nu** (publier maintenant). Dans l'éditeur, ces boutons s'affichent encore en néerlandais.

Le message **Gepubliceerd** (publié) s'affiche et votre site est en ligne. Vous pouvez aussi publier sans ouvrir l'éditeur : dans **Site web** → **Aperçu**, la carte d'état contient aussi un bouton **Publier**.

La publication est possible avec toutes les formules, y compris Desk (gratuit).

## Mon site web n'est pas encore en ligne, que faire ?

Si **Site web** → **Aperçu** affiche « Pas encore en ligne » ou « Pas encore publié », vous n'avez encore jamais publié. Ouvrez l'éditeur via **Modifier le site** et cliquez sur **Publiceer**. Inutile d'avoir terminé votre site : vous pourrez toujours republier plus tard.

Parfois, un avertissement s'affiche d'abord lors de la publication, par exemple « Votre site contient encore du texte d'exemple », « Il manque des informations d'entreprise sur les pages légales » ou « Votre site affiche votre adresse e-mail de connexion ». Ces avertissements ne vous bloquent pas. Choisissez **Modifier d'abord** pour corriger, ou **Publier quand même** pour mettre en ligne tout de suite.

## Que signifie « modifications prêtes à publier » ?

Tout ce que vous changez dans l'éditeur est conservé comme brouillon. Tant que vous ne republiez pas, vos visiteurs voient encore la version précédente. Vous le reconnaissez à :

- un petit point sur le bouton **Publiceer** dans l'éditeur ;
- le texte « klaar om te publiceren » (prêt à publier) en bas de l'éditeur ;
- « 1 modification prête à publier » (ou plus) dans **Site web** → **Aperçu**.

Cliquez sur **Publiceer** pour tout mettre en ligne d'un coup. Vous préférez abandonner vos modifications ? Choisissez **Revenir à la version en ligne** dans le menu aux trois points.

Les pages sur **Concept** (brouillon) restent invisibles, même après publication. Passez une page sur **Live** (en ligne) si elle doit apparaître.

## À quelle adresse se trouve mon site web ?

- **Adresse gratuite :** à votre première publication, votre site reçoit une adresse gratuite basée sur le nom de votre entreprise, par exemple `votreentreprise.mycompanydesk.site`. D'ici là, vous voyez « Votre adresse apparaît dès que vous publiez ».
- **Propre domaine :** vous voulez votre site sur votre propre nom de domaine, par exemple `votreentreprise.fr` ? C'est possible avec Office. Allez dans **Site web** → **Domaine & e-mail** et suivez les étapes. Voir [Connecter votre propre domaine et les serveurs de noms](/fr/faq/connect-domain).

## Comment mettre mon site web hors ligne ?

Dans **Site web**, cliquez sur les trois points en haut à droite et choisissez **Mettre le site hors ligne**. Confirmez avec **Mettre hors ligne**. Vos visiteurs voient alors un message indiquant que le site est temporairement indisponible. Votre version publiée est conservée : avec **Remettre le site en ligne**, elle est de nouveau en ligne immédiatement.

Ne laissez pas votre site trop longtemps hors ligne : après quelques jours, Google le retire des résultats de recherche, et il faut des semaines pour qu'il y revienne.
