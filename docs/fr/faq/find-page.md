Pour trouver des pages dans l'application :
• Utilisez le menu latéral (sur votre téléphone, la barre en bas et le bouton de menu). Après le Tableau de bord, il est organisé en Ventes (Factures, Devis, Bons d'intervention, Récurrent, Clients, Catalogue), Gestion (Agenda, Tâches, Projets, Documents, Contrats, Propriétés), Finance (Chiffres, Dépenses, Impôts, Rapports, Comptabilité) et Communication (Boîte de réception, Newsletters, Site web)
• Les Paramètres se trouvent aussi dans le menu. Vos propres données y figurent sous « À votre sujet » ; Données de l'entreprise, Modules et Personnes ayant accès sous « Votre entreprise »
• Appuyez sur Cmd+K (Mac) ou Ctrl+K (Windows/Linux) pour chercher et aller directement à une page.

Astuce : s'il manque un élément de menu, vérifiez d'abord dans Paramètres › Modules que ce module est activé. Si vous travaillez comme membre d'équipe, le propriétaire choisit dans Paramètres › Personnes ayant accès les pages que vous voyez.
