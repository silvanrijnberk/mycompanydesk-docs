MyCompanyDesk n'a pas d'API publique ni de webhooks. Vous ne pouvez donc pas créer de clés API.

Pour utiliser vos données dans un autre système, vous avez ces options sur chaque abonnement :
1. Ouvrez **Paramètres › Télécharger les données** et téléchargez vos factures, clients et dépenses en fichier CSV par rubrique, ou tout ensemble en sauvegarde JSON
2. Ou donnez gratuitement l'accès à votre comptable dans **Paramètres › Votre comptable**

Pour en savoir plus, consultez [Intégration API](/fr/advanced/api).
