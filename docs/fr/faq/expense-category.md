Pour définir ou modifier une catégorie de dépense :
1. Ouvrez la dépense en mode édition
2. Trouvez le menu déroulant « Catégorie »
3. Sélectionnez une catégorie dans la liste de votre espace de travail (catégories standard ou catégories que vous avez ajoutées)
4. Enregistrez la dépense

Les catégories standard suivent la déclaration fiscale néerlandaise, afin que votre comptabilité corresponde à votre déclaration. Vous pouvez ajouter vos propres catégories dans **Paramètres > Catégories de dépense**, puis les modifier, les archiver ou les supprimer. Si une catégorie contient déjà des dépenses ou des dépenses récurrentes, vous ne pouvez pas la supprimer; archivez-la pour la masquer dans le formulaire. Une catégorie archivée reste visible dans le menu déroulant pour les dépenses qui l'utilisent déjà, avec la mention « (archivée) », afin que vous puissiez continuer à modifier ces dépenses. Utilisez les catégories de façon cohérente afin que les filtres, listes et rapports restent faciles à vérifier.
