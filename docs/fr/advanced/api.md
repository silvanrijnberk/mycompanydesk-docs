# Intégration API

MyCompanyDesk ne propose pas d'API REST publique ni de webhooks pour vos propres intégrations. Vous ne pouvez donc pas créer de clés API ni configurer de webhooks.

## Utiliser vos données dans un autre système

Si vous souhaitez utiliser vos données ailleurs, vous pouvez le faire avec tous les abonnements, de ces façons :

- **Télécharger les données** : sous **Paramètres › Télécharger les données**, vous récupérez vos factures, clients et dépenses sous forme de fichier CSV par section, ou le tout dans une seule sauvegarde JSON. Les photos et PDF de vos justificatifs n'y figurent pas ; ils restent avec la dépense elle-même.
- **Votre comptable** : donnez gratuitement accès à votre comptable sous **Paramètres › Votre comptable**. Il voit alors toujours vos derniers chiffres, sans que vous ayez à envoyer de fichiers.
