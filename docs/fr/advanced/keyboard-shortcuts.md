# Raccourcis clavier

MyCompanyDesk garde volontairement un nombre réduit de raccourcis clavier. Voici ceux qui fonctionnent réellement.

## Fenêtre de recherche

| Raccourci | Action |
|---|---|
| `Cmd+K` (Mac) / `Ctrl+K` (Windows/Linux) | Ouvrir ou fermer la fenêtre de recherche |

La fenêtre de recherche est le moyen le plus rapide de naviguer dans l'application :

- Tapez au moins deux caractères pour rechercher parmi vos clients, factures, dépenses, devis, tâches, factures récurrentes, dépenses récurrentes, bons d'intervention, articles du catalogue, documents et conversations de la boîte de réception (ainsi que les projets, contrats et propriétés si ces modules sont activés).
- Les paramètres sont également consultables : tapez par exemple "TVA" ou "rappels" pour accéder directement à la carte de paramètres correspondante.
- Les actions rapides vous permettent d'accéder à n'importe quelle section ou de créer une nouvelle facture, un devis, une dépense ou un client.
- Les puces de filtre sous le champ de recherche limitent les résultats à un seul type.

Dans la fenêtre de recherche :

| Raccourci | Action |
|---|---|
| `Haut` / `Bas` | Parcourir les résultats |
| `Entrée` | Ouvrir le résultat sélectionné |
| `Échap` | Fermer la fenêtre de recherche |

## Échap

La touche `Échap` vous fait remonter d'un niveau à la fois :

- Pendant la saisie dans un champ, elle retire le focus de ce champ.
- Lorsqu'une boîte de dialogue est ouverte, elle la ferme.
- Sur une page de détail, elle vous ramène à la liste (comme le bouton retour).

## Formulaires

| Raccourci | Action |
|---|---|
| `Cmd+S` / `Ctrl+S` | Enregistrer le formulaire (sur une facture, c'est **Enregistrer comme brouillon**) |

Cela fonctionne dans les formulaires dotés d'une barre d'enregistrement en bas, comme une facture, une dépense, un bon d'intervention, un contrat ou une facture récurrente. Si une boîte de dialogue est ouverte, le raccourci ne fait rien.

Les touches habituelles du navigateur fonctionnent partout : `Tab` et `Maj+Tab` passent d'un champ à l'autre, et `Entrée` envoie la plupart des formulaires.

## Agenda

| Raccourci | Action |
|---|---|
| `A` | **Ajouter une entrée** |

Le raccourci ne réagit pas pendant que vous tapez dans un champ.

## Boîte de réception

Dans la boîte de réception, vous travaillez avec de simples touches de lettre, tant que vous ne tapez pas dans un champ :

| Raccourci | Action |
|---|---|
| `c` | Nouveau message |
| `r` | Répondre |
| `j` / `k` | Conversation suivante / précédente |
| `e` | Terminé |
| `s` | Épingler ce message |
| `u` | Retour à la liste |
| `/` | Rechercher |
| `#` | Supprimer |
| `!` | Marquer comme spam |
| `?` | Afficher ou masquer l'aperçu **Raccourcis clavier et filtres de recherche** |

## Éditeur de site

Pendant la modification de votre site web :

| Raccourci | Action |
|---|---|
| `Cmd+Z` / `Ctrl+Z` | Annuler |
| `Cmd+Maj+Z` / `Ctrl+Maj+Z` ou `Ctrl+Y` | Rétablir |
| `Alt+Haut` / `Alt+Bas` | Déplacer le bloc sélectionné |
| `Haut` / `Bas` | Sélectionner le bloc précédent ou suivant |
| `Retour arrière` / `Suppr` | Supprimer le bloc sélectionné |
| `Cmd+D` / `Ctrl+D` | Dupliquer le bloc |
| `Cmd++` / `Cmd+-` (`Ctrl` sous Windows/Linux) | Zoomer et dézoomer |
| `Cmd+0` / `Ctrl+0` | Ajuster à la fenêtre |
| `Échap` | Fermer la sélection, le panneau ou l'aperçu |
| `Cmd+/` / `Ctrl+/` | Aperçu de tous les raccourcis |

Vous pouvez aussi ouvrir cet aperçu avec le bouton clavier en bas de la barre latérale de l'éditeur.

Tant qu'un champ de texte est actif, annuler et rétablir s'appliquent au texte que vous saisissez et les flèches déplacent le curseur. Cliquez d'abord en dehors du champ pour annuler une étape de modification complète.
