# Paramètres du profil

La page **Profiel** est l'endroit où vous réglez les informations qui concernent uniquement votre compte utilisateur. Les autres membres du même espace de travail ne voient pas ces choix.

## Informations personnelles

Mettez à jour votre nom, votre adresse e-mail et votre numéro de téléphone. L'adresse e-mail est utilisée pour la connexion, les notifications et la récupération du mot de passe.

## Sécurité

### Mot de passe

Choisissez un mot de passe fort. Si vous l'avez oublié, utilisez **Wachtwoord vergeten** sur la page de connexion pour le réinitialiser.

### Authentification à deux facteurs

Vous pouvez ajouter une couche de sécurité supplémentaire en activant l'authentification à deux facteurs. Une fois activée, chaque connexion demande également un code provenant de votre application d'authentification. Conservez vos codes de récupération en lieu sûr.

## Paramètres d'affichage

Sous **Affichage**, vous définissez l'apparence de l'application pour vous sur cet appareil.

- **Thème** : Licht (clair), Donker (sombre) ou Vanzelf (automatique). Automatique suit votre appareil : clair le jour, sombre le soir.
- **Taille du texte** : Normaal (normal) ou Groot (grand), pour une lecture plus confortable.
- **Langue de l'application** : néerlandais, anglais, allemand ou français. Cela modifie uniquement les menus et boutons pour vous ; la langue des factures et devis se choisit par document.
- **Chiffres au-dessus de vos listes** : choisissez **Détaillé** (avec résumés et totaux) ou **Épuré** (uniquement la liste). Épuré masque les bandeaux d'indicateurs et les cartes de résumé au-dessus et à côté des pages de listes, comme les factures, les dépenses, les devis et l'agenda. Ce réglage est mémorisé par appareil et se synchronise entre les onglets.
- **Paramètres avancés** : un interrupteur par appareil qui révèle des options techniques supplémentaires dans l'application, comme les contrôles DNS et SSL sur les pages de domaine. Laissez-le désactivé sauf si vous en avez besoin.

## Notifications

Choisissez pour quels événements vous recevez un e-mail ou une notification push. Vous pouvez activer ou désactiver des catégories comme les rappels de factures, les expirations de contrats et les mentions.

## Modes de paiement

Ajoutez votre propre carte de crédit ou autre mode de paiement. Ils sont utilisés pour les achats dans l'application, comme les paiements d'abonnement.

## Entreprise

La section **Bedrijf** affiche l'espace de travail dans lequel vous êtes actuellement connecté et votre rôle à l'intérieur. Si vous avez accès à plusieurs espaces de travail, vous pouvez basculer entre eux ici.

## Où le trouver

- Cliquez sur votre avatar ou vos initiales en haut à droite.
- Choisissez **Profiel** dans le menu.
